# Early Web3 Radar 🚀

A web3 discovery tool that scans Twitter daily to find new and promising blockchain projects.

## Features

- Discovers projects with Twitter accounts less than 30 days old
- Filters for accounts with under 1,000 followers
- Identifies genuine web3 projects (not personal accounts)
- Checks for signs of active development
- Updates daily with new discoveries

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Supabase (Database)
- Vercel (Deployment)

## Setup

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up environment variables (see below)
4. Run development server: `npm run dev`
